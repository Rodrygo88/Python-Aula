# Desafios de Python - Curso em Vídeo

Repositório com exercícios resolvidos em Python, feitos durante os estudos de lógica de programação e fundamentos da linguagem no curso de Python do Curso em Vídeo.

A ideia aqui é registrar a evolução passo a passo: desde o clássico `Olá, Mundo!` até exercícios com estruturas de repetição, listas, dicionários, funções, módulos, tratamento de dados e consumo simples de requisições HTTP.

## Sobre o projeto

Este repositório reúne **114 desafios práticos** organizados em arquivos individuais. Cada exercício foi pensado para treinar um conceito específico da linguagem e reforçar a prática com pequenos problemas.

Alguns temas trabalhados:

- Entrada e saída de dados
- Operadores aritméticos
- Condições simples e compostas
- Laços `for` e `while`
- Manipulação de strings
- Listas, tuplas e dicionários
- Funções
- Módulos e pacotes
- Validação de dados
- Uso de bibliotecas como `random`, `math`, `datetime`, `time`, `pygame` e `requests`

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Rodrygo88/python_desafios.git
```

2. Acesse a pasta dos exercícios:

```bash
cd python_desafios/Projeto/Python
```

3. Execute o exercício desejado:

```bash
python "Exercício - 001.py"
```

Em alguns ambientes, o comando pode ser:

```bash
python3 "Exercício - 001.py"
```

## Dependências

A maioria dos exercícios usa apenas bibliotecas padrão do Python. Alguns desafios específicos podem precisar de pacotes externos:

```bash
pip install pygame requests
```

## Objetivo

Este projeto serve como registro da minha jornada aprendendo Python, praticando lógica e criando uma base sólida para projetos maiores.
